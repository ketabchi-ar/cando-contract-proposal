# قرارداد رسمی طراحی و راه‌اندازی وب‌سایت کافه بوردگیم کندو (Cando Cafe)
### آژانس دیجیتال پالت × آقایان مصطفی رجائی و آرش فریدی

وب‌اپلیکیشن تعاملی قرارداد و پروپوزال رسمی بازطراحی و راه‌اندازی مجدد وب‌سایت فروشگاه آنلاین کافه بوردگیم کندو (`https://candocafe.ir/`).

---

### مشخصات و تعهدات کلیدی:
1. **دامنه پروژه:**
   - نصب و راه‌اندازی مجدد فروشگاه اینترنتی با هدف فروش آنلاین بازی‌های رومیزی.
   - بازطراحی صفحات با هویت بصری قبلی (تاس پنیر، تم رنگی زرد شاداب و کانسپت We Serve Fun).
   - صفحات: صفحه اصلی، فروشگاه، تک‌محصول، وبلاگ، آرشیو وبلاگ، درباره ما، تماس با ما، پنل کاربری اختصاصی.
2. **امکانات اختصاصی:**
   - درج حداقل ۳۰ محصول اولیه همراه با جلسه/ویدیوی آموزشی.
   - سیستم اختصاصی به‌روزرسانی خودکار و دستی قیمت‌ها (پلاگین اختصاصی آژانس پالت).
   - فیلترهای تخصصی بوردگیم (رده سنی، تعداد نفرات، زمان بازی، مکانیزم).
   - کانفیگ کش لایت‌اسپید (LiteSpeed Cache)، سئو پایه و نقشه سایت، بکاپ‌گیری خودکار.
   - اتصال درگاه‌های بانکی شاپرک، دیجی‌پی اقساطی، پیامک خدماتی SMS.ir و اینماد.
3. **زمان‌بندی:** ۱۰ تا ۱۵ روز کاری.
4. **سیستم احراز هویت و امضای دوگانه:** انتخاب سریع بین شماره آقای مصطفی رجائی (09171199745) و آقای آرش فریدی (09172256940).
